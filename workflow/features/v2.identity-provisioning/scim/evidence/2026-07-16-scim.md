# SCIM v2 provisioning evidence

Feature: `v2.identity-provisioning.scim`
Timestamp: 2026-07-16 12:05 CDT

## Scope

Implemented SCIM v2 provisioning API surfaces for service metadata, users, and explicit unsupported groups behavior.

## Changes

- Added identity provisioning service with mailbox create/replace/patch/disable behavior, verifier-backed SCIM bearer-token authentication, and synchronization into the daemon mailbox/passdb view.
- Added SCIM endpoints:
  - `GET /scim/v2/ServiceProviderConfig`
  - `GET /scim/v2/ResourceTypes`
  - `GET /scim/v2/Schemas`
  - `GET /scim/v2/Users`
  - `POST /scim/v2/Users`
  - `GET /scim/v2/Users/{id}`
  - `PUT /scim/v2/Users/{id}`
  - `PATCH /scim/v2/Users/{id}`
  - `DELETE /scim/v2/Users/{id}`
  - `GET /scim/v2/Groups` explicit unsupported error
- Implemented SCIM user mapping:
  - `userName` -> mailbox email
  - `displayName` / `name.formatted` -> display name
  - `active` -> enabled flag
  - `password` -> Django PBKDF2-SHA256 verifier string
- Implemented PATCH support for active, displayName/name.formatted, and password.
- DELETE disables the mailbox and does not delete mail data.
- SCIM failure paths return SCIM error objects.
- Provisioning mutations and denied/failure paths emit audit events through the identity service.
