## Blocking persistence observation

Native classification found localStorage0/sessionStorage1. The sole key is
htmx-current-path-for-history, its value matches the current canonical public
inventory path, and it contains no fixture credential. The unmodified pinned
HTMX asset's top-level $t(location.pathname+location.search) writes this key before
DOMContentLoaded/configuration. historyEnabled:false and historyCacheSize:0 do not
prevent it. No history HTML snapshot was observed.

The binding contract explicitly prohibits localStorage, history snapshots and
secret-bearing state; the worker's stronger zero-session-storage oracle also
rejects path-only bookkeeping. Parent must settle that distinction and the effect
of arbitrary tolerated query strings. This is not reported as a proven secret leak,
nor silently accepted as harmless. The assertion remains failing. Changing shared
vendor bytes or overriding browser storage APIs was NOT authorized or attempted.
